# Mapa de navegação da documentação

Índice dos arquivos Markdown mantidos sob `docs/`. Ao adicionar um novo
documento `.md` neste diretório, inclua-o na lista abaixo.

## Documentação disponível

- `docs/mapa-documentacao.md` — este arquivo: índice vivo da documentação em `docs/`.

Observações: os demais materiais de referência do repositório ficam na raiz
(`README.md`, visão geral do projeto; `AGENTS.md`, convenções para agentes) e,
para permissões udev do G403, em `docs/udev/99-logitech-g403-hidraw.rules`.
